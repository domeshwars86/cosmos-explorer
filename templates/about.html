About the Project

COSMOS — Interactive Galaxy & Solar System Explorer

COSMOS is an educational visualization project built to make the scale, structure, and science of our Solar System and the Milky Way tangible and explorable — through real 3D interaction rather than static pages of text.

Purpose

The Solar System cannot be shown at true scale and true distance simultaneously on a screen — so COSMOS is explicit about which visualization mode you're viewing and what it does and doesn't represent (see the Solar System page's Visual / Size / Distance / Scientific modes). Every statistic is sourced from reputable astronomy references and clearly labeled as approximate where appropriate.

Technology

Built with a Python & Flask backend serving a JSON API, and a vanilla JavaScript + Three.js frontend — no heavy frontend framework, no build step required.

How the 3D Visuals Work

Every planet, moon, and the Sun are rendered with procedurally generated textures drawn on an HTML canvas at load time — rather than downloaded image files — so the visuals are fully self-contained, load quickly, and never break due to a missing asset. Colors and surface patterns are inspired by each body's real appearance but are illustrative, not photographic.

Data Sources & Disclaimer

Planetary and lunar statistics are drawn from and cross-checked against publicly published reference data from NASA, NASA JPL, and ESA fact sheets, then written as original summaries. Values are approximate and may vary slightly between sources depending on measurement method; where genuinely uncertain, this is noted directly on the relevant page. Visualizations are for educational purposes and are not necessarily drawn to physical scale unless explicitly labeled "Scientific Mode." COSMOS is an independent project and is not affiliated with or endorsed by NASA, ESA, or any space agency.

Creator

Designed and built as a portfolio-quality educational demo showcasing full-stack development, 3D web graphics, and data-driven UI design.
